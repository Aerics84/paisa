    Dependency Freeze 2026-10¶

    Deliberate Pins and Follow-ups¶

    • beancount 3.2.3: adopted on 2026-10-29 with beanquery 0.2.0. bean-report is replaced by BQL (BALANCES, SELECT ... FROM prices). See Dependency Maintenance.
    • npm 12.2.1: adopted on 2026-10-29 after the default-branch gate passed; see Dependency Maintenance.
    • TypeScript 7.0.2: intentionally ignored for major updates until the surrounding toolchain accepts it.
    • Remaining tooling-only Go modules: 53 modules outside the import graph still have newer releases. The 20 compiled-graph modules were refreshed on 2026-10-29; direct modules are current.
    • NixOS 26.11: next refresh within two weeks of release.
    • hledger 1.52.4: pinned through a Hackage source override because nixpkgs (26.05 and master) still packages 1.52; issue #2254 is fixed since 1.41.
    • Windows release dry run: re-run the ci/windows-* workflow after the hosted-runner stall; the workflow fixes are committed but no green Windows run exists yet.
    • PDF worker-path coverage: the fixture golden verifies extraction; a browser-level upload test that exercises the production worker URL remains a follow-up.

    Post-Freeze Review Fixes¶

    A whole-branch review after the freeze produced one Critical and four Important findings. Fix commit bd62c3ab9a31b55fabc185d143b905d0eff95caa:

    • Treats npm audit exit codes other than 0/1, and any nonzero govulncheck exit in -json mode, as scanner errors (exit 2); govulncheck error records are rejected too. scripts/security-gate.test.mjs covers each failure path.
    • Runs the CI regression test with the .bun-version Bun (1.4.4) inside the Nix shell instead of the Nix-packaged 1.3.13.
    • Narrows the P-UI claim to route-level verification and corrects the phase status wording.

    The dependency state is unchanged: the lockfile, artifact and fixture manifests still match the freeze hashes above. The PDF worker-path test remains a recorded follow-up.

    Release Dry Run¶

    The ci/* draft-release dry run was executed at commit 2052410 (the only difference from the freeze commit is .github/workflows/windows.yml):

    • Linux App Release: success (static ledger 3.4.1, Wails build, .deb).
    • Linux CLI Release: success.
    • Mac OS AMD64 Release: success (ledger 3.4.1 from the corrected Homebrew formula).
    • Mac OS ARM64 Release: success.
    • Windows Release: pass on 2026-10-29 at commit efa696b (run 40856347900). The run built paisa-cli-windows-amd64.exe (80.7 MB) and paisa-app-windows-amd64.exe (24.9 MB, NSIS installer). Two ledger 3.4.1 MinGW build defects had to be fixed in the workflow: BYTE_ORDER is undefined under MinGW (-DBYTE_ORDER=1234 -DLITTLE_ENDIAN=1234 -DBIG_ENDIAN=4321) and the detected readline/libedit did not declare history_expand, so the embedded CLI is built with -DHAVE_EDIT=0 -DHAVE_READLINE=0. The draft release was deleted afterwards.

    The release action created one draft release with an empty tag; it was deleted after the run. No tags were pushed. Logs are in .cache/dependency-refresh/matrix/p-release-*.log (local).
